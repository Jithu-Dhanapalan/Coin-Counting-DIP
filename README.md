# Coin Counting and Segmentation Using Digital Image Processing

## Project Description

This project implements a coin counting and segmentation system using traditional Digital Image Processing techniques.

## Techniques Used

- RGB to Grayscale Conversion
- Histogram Analysis
- Histogram Equalization
- Contrast Stretching
- Gaussian Smoothing
- Noise Restoration
- Mean and Median Filtering
- MSE, PSNR and SSIM
- Otsu Thresholding
- Morphological Operations
- Distance Transform
- Watershed Segmentation
- Connected Component Analysis

## Results

The system was tested on five coin images.

- Total actual coins: 36
- Total detected coins: 35
- Overall counting accuracy: 97.22%

One coin was missed in Image 4, which was discussed as a failure case in the project.
